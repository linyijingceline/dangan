# 伙伴档案（partner-profile）

收集和展示团队成员的个人档案：成员自己填写，页面按人展示成一张张档案卡，管理员可以增删改。

- **仓库地址**：https://github.com/linyijingceline/dangan
- **线上地址**：https://partner-profile-d0fjkj7a9c4abacc-1495948086.tcloudbaseapp.com/
- **阶段**：Day 7 —— MVP 已跑通（填写 / 列表 / 详情 / 管理 四个页面都能用）
- **怎么跑起来**：见 [RUNBOOK.md](./RUNBOOK.md)（本地启动、云函数部署、排查方法）

## 谁用这个系统

| 角色 | 能做什么 |
|---|---|
| 团队成员 | 打开填写页，填自己的信息并提交 |
| 团队负责人（管理员） | 输口令进管理页，看全部档案（含电话住址），新增、编辑、删除 |

## 四个页面

| 页面 | 文件 | 说明 |
|---|---|---|
| 列表页 | `index.html` | 一张张档案卡，点进去看详情 |
| 填写页 | `submit.html` | 无需注册，5 项必填，顶部有信息用途告知 |
| 详情页 | `profile.html` | 只显示公开信息，不含电话住址 |
| 管理页 | `admin.html` | 口令进入，可增删改，删除有二次确认 |

## 数据字段

- 全员可见：姓名、专业、学校、生日、爱好、加入时间
- **仅管理员可见**：电话、家庭住址、备注

> 敏感字段的隔离靠**数据库权限**实现，不是前端把号码打码显示。
> 详情见 [TECH_DESIGN.md](./TECH_DESIGN.md) 第六节。

## 技术路线

静态网页 + 云函数（唯一入口）+ CloudBase PostgreSQL。
**网页不直接连数据库**，所有请求都经过云函数，由它决定返回哪些字段。

## 隐私约定

- 仓库里只有代码，**不存任何真实档案数据、口令或密钥**
- `.env` 与本地导出的数据文件已被 `.gitignore` 挡在仓库外
- 示例文件 `.env.example` 里的值全部是假的
