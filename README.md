# 伙伴档案（partner-profile）

收集和展示团队成员的个人档案：成员自己填写，页面按人展示成一张张档案卡，管理员可以增删改。

- **阶段**：Day 2（环境与仓库搭建）已完成，功能尚未开发
- **目标**：7 天内做出第一个可用版本（MVP）
- **技术路线**：静态网页 + 托管数据库（页面托管 GitHub Pages，数据存云端数据库服务）

## 谁用这个系统

| 角色 | 能做什么 |
|---|---|
| 团队成员 | 打开填写页，填自己的信息并提交 |
| 团队负责人（管理员） | 看全部档案，包括敏感信息；新增、编辑、删除任一条档案 |

## 计划中的页面

1. 填写页 —— 成员提交自己的信息
2. 档案列表页 —— 一张张档案卡
3. 档案详情页 —— 某个人的完整信息
4. 管理页 —— 管理员增删改（需口令进入）

## 数据字段

- 全员可见：姓名、专业、学校、生日、爱好、加入时间、备注
- 仅管理员可见（敏感）：电话、家庭住址

> 敏感字段的读取权限设在数据库侧，不是靠前端把号码打码显示。

## 隐私约定

- 仓库里只有代码，**不存任何真实档案数据**
- `.env` 与本地导出的数据文件已被 `.gitignore` 挡在仓库外
- 示例文件 `.env.example` 里的值全部是假的

## 本地查看

直接用浏览器打开 `index.html` 即可，不需要安装任何东西。
